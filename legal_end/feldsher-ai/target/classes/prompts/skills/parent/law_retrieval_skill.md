# 法律法规检索父Skill

## Skill定义
这是所有法律法规检索类Skill的父Skill，定义了法条检索的通用框架和标准。

## 检索优先级

### 一级检索（必须检索）
1. **当前案由对应的专门法律**
   - 婚姻家事 → 《民法典》婚姻家庭编
   - 劳动争议 → 《劳动合同法》《劳动争议调解仲裁法》
   - 合同纠纷 → 《民法典》合同编
   - 刑事诉讼 → 《刑法》《刑事诉讼法》

2. **最高人民法院相关司法解释**
   - 关于适用《民法典》婚姻家庭编的解释
   - 关于审理劳动争议案件适用法律问题的解释
   - 等...

### 二级检索（根据案情）
1. **行政法规和部门规章**
2. **地方性法规**
3. **最高人民法院的指导意见、会议纪要**

## 检索关键词策略

### 通用关键词模板
```
{案由} + {核心事实} + {争议焦点} + {法律后果}
```

### 关键词组合示例
- 离婚诉讼 + 分居 + 感情破裂 + 准予离婚
- 劳动争议 + 拖欠工资 + 经济补偿金 + 赔偿
- 合同纠纷 + 违约 + 解除合同 + 违约责任

## 法条关联性评估标准

### 高关联性（必须展示）
- 法条直接对应本案的核心事实
- 法条直接回应用户的核心诉求
- 法条是处理本案的主要法律依据

### 中关联性（可选择性展示）
- 法条与本案事实有一定关联
- 法条可能影响案件的处理结果
- 法条是辅助性的法律依据

### 低关联性（不展示）
- 法条与本案事实关联度低
- 法条不适用于本案的具体情形
- 法条已被废止或修订

## 法条内容整理规范

### 整理原则
1. **原文引用**：准确引用法条原文，不得修改
2. **条文编号**：明确标注法律名称和条文编号
3. **要点提炼**：用通俗语言提炼法条核心要点
4. **关联性分析**：说明法条与本案的具体关联

### 整理模板
```
【法律名称】
【条文编号】 【条文标题】

【法条原文】

【核心要点】
1. 要点一：...
2. 要点二：...

【与本案关联】
...

【参考建议】
...
```

## 子Skill继承规范

每个子Skill（按案由划分）需要：
1. 继承本父Skill的检索框架
2. 根据案由特点，定制专属检索策略
3. 提供该案由常见的法律条文清单
4. 保持输出格式一致
